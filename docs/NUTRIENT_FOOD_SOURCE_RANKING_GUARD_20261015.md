# 영양소 ④ 식품원·함량 작성 규칙 — 2026-10-15

이 문서는 사용자 확정 소제목 **`풍부한 식품 TOP7과 각 식품의 평균 함유량은 얼마인가?`**를 작성할 때 숫자를 만들거나 같은 원료 파생품으로 순위를 채우는 오류를 막기 위한 규칙이다.

## 1. 독자에게 먼저 보여줄 것

④의 첫 답은 다음 두 가지다.

1. 어떤 식품에 많이 들어 있는가?
2. 각 식품에 평균적으로 얼마나 들어 있는가?

기본 표:

| 순위 | 식품 | 평균 함유량 | 기준 |
| ---: | --- | ---: | --- |
| 1 | 식품 A | 값 | 100g 등 |

분석방법·자료를 찾은 과정·작성자의 비교 판단 과정은 기본 표의 열로 만들지 않는다.

## 2. 단일 DB 우선 순위를 없앤다
- USDA는 자동 첫 번째 자료원이 아니다. 국내 국가표준식품성분표·식품안전나라, 국내외 실측 논문, NIH 자료, USDA 등 **해당 성분의 실제 측정값이 있는 자료**를 먼저 폭넓게 찾는다.
- 식품성분 DB로 사람의 기억력·혈압·항염증 효과를 입증하지 않는다. 건강상 이점은 별도의 사람 연구에서 확인한다.
- 여러 자료에서 식품의 상태·가식부·조리법·단위가 같은지 살펴보고, 기준이 다르면 무리하게 한 순위로 혼합하지 않는다.
- 공개 본문은 식품명과 함량이 중심이다. 출처기관 소개·비교 메모는 본문에 길게 쓰지 않는다.

## 3. TOP7 후보를 충분히 찾는다

- 대표 식품 하나만 확인하고 끝내지 않는다.
- 국내 독자가 실제로 아는 식품명과 원료명을 넓게 확인한다.
- 같은 원료의 가공품 여러 개를 서로 다른 식품처럼 세지 않는다.
- 단순히 검출됐다는 이유만으로 고함량 식품이라고 쓰지 않는다.
- 직접 섭취하는 식품과 그 성분을 이용해 만든 가공·발효식품의 성격이 다르면 구분한다.

## 4. 숫자를 만들지 않는다

- 실제 평균값만 `평균 함유량`이라고 쓴다.
- 범위 자료는 범위 그대로 표시한다.
- 단일 측정값은 단일값이라고 구분한다.
- `원료 함량 × 제품 배합률` 같은 계산값을 실제 평균값으로 바꾸지 않는다.
- 추정·환산·계산값을 TOP 순위에 넣지 않는다.
- 제품 표시량·최저 보장량을 식품 자체의 평균 함량으로 바꾸지 않는다.
- 제품의 1회 제공량을 식품의 풍부함 순위 근거로 사용하지 않는다.

## 5. 같은 원료 파생품으로 순위를 채우지 않는다

예:

`강황가루 → 강황 4.2% 카레 → 강황 2.8% 카레`

이런 항목은 하나의 핵심 원료에서 파생된 제품이므로 천연 식품 TOP3처럼 취급하지 않는다.

## 6. 7개를 다 확보하지 못했을 때

- TOP7을 맞추기 위해 숫자·식품·순위를 만들지 않는다.
- 확인 가능한 식품을 최대한 더 찾는다.
- 그래도 7개보다 적으면 확보한 식품과 함량을 우선 보여준다.
- `왜 자료가 부족한지`, `왜 직접 비교가 어려운지` 같은 설명으로 본문을 채우지 않는다.
- 기준 차이가 독자에게 꼭 필요하면 `기준` 열이나 짧은 주석 한 문장으로 끝낸다.

## 7. 실제 섭취량도 함께 생각한다

- 향신료·분말처럼 100g을 한 번에 먹지 않는 식품은 실제 1회 사용량도 짧게 안내한다.
- 100g 수치가 높다는 이유만으로 일상에서 가장 많은 양을 섭취하게 된다고 단정하지 않는다.

## 8. 저장 전 한 번만 확인

- TOP7 후보를 충분히 찾았는가?
- 식품명이 일반 독자가 이해할 이름인가?
- 같은 원료 파생품으로 순위를 채우지 않았는가?
- 평균·범위·단일값을 구분했는가?
- 추정·환산·계산값을 실제 평균 함유량처럼 쓰지 않았는가?
- 제품 1회 제공량을 풍부함 순위로 사용하지 않았는가?
- 표에서 가장 먼저 보이는 정보가 `식품명 + 함유량`인가?
- 작성자의 확인 과정 설명이 독자용 정보보다 길어지지 않았는가?
