# 영양소 ④ 식품원·함량 순위 재발 방지 규칙 — 2026-10-15

이 문서는 영양소 원고의 `④ 풍부한 식품 TOP7·평균 함량` 작성에서 식품원 후보 누락, 동일 원료 파생품으로 순위 채우기, 추정값 순위화를 막기 위한 영구 작성 규칙이다.

## 적용 순서

1. **식품원 후보군을 먼저 넓게 조사한다.**
   - 주제 성분의 `food source / dietary source / occurrence / quantitative analysis`를 확인한다.
   - 식물성 성분은 해당 종 하나만 보지 말고 같은 속·가까운 식용 식물과 국내 통용 원료명까지 후보를 확인한다.
   - 특정 원료가 대표 급원이라는 사실과, 그 성분이 다른 식품에도 존재하는지는 별도로 확인한다.

2. **존재 여부와 순위화를 분리한다.**
   - 먼저 어떤 식품에서 해당 성분이 확인되는지 후보 목록을 만든다.
   - 그 다음 동일 DB·동일 분석법·동일 단위·동일 상태처럼 직접 비교 가능한 항목만 TOP7/TOP5/TOP3에 넣는다.
   - 비교 가능한 3개 식품도 확보하지 못하면 순위를 만들지 않고 `확인 가능한 식품과 함량`으로 설명한다.

3. **서로 독립된 식품을 순위화한다.**
   - 하나의 핵심 원료를 배합한 가공품 여러 개를 서로 다른 천연 급원처럼 취급하지 않는다.
   - 예: `강황가루 → 강황 4.2% 카레 → 강황 2.8% 카레`처럼 같은 원료의 배합률만 다른 제품으로 TOP3를 채우지 않는다.
   - 가공 형태 비교가 검색 의도상 필요하면 별도 `섭취 형태 비교`로 설명하고 천연 식품원 순위와 분리한다.

4. **추정값으로 TOP 순위를 만들지 않는다.**
   - `원료 실측 함량 × 가공식품 속 원료 배합률`처럼 계산한 값은 순위 근거로 사용하지 않는다.
   - 실측값과 계산·환산·추정값을 같은 TOP 표에서 비교하지 않는다.
   - 추정값은 독자의 실제 섭취량을 설명하는 참고 계산으로 필요할 때만 순위표 밖에서 `추정`임을 명시한다.

5. **평균·범위·실측·추정을 구분한다.**
   - 실제 평균값만 `평균 함량`이라고 쓴다.
   - 범위 자료는 범위로, 단일 분석값은 단일값으로 표시한다.
   - 제품 표시량·최저 보장량·배합비 환산값을 식품 자체의 평균 함량처럼 바꾸지 않는다.

## 저장 전 필수 확인

④를 완료하기 전에 작성자는 아래를 한 번 확인한다.

- 이 성분이 다른 식품·같은 속의 식용 식물에서도 확인되는지 조사했는가?
- TOP 항목들이 서로 독립된 식품인가, 같은 원료를 넣은 파생 가공품인가?
- 순위에 들어간 모든 수치가 직접 측정된 비교 가능한 값인가?
- `추정`, `환산`, `배합률 적용`으로 만든 값을 TOP 순위에 넣지 않았는가?
- 동일 기준으로 3개도 확보하지 못했다면 억지 TOP3 대신 순위 없는 표로 바꿨는가?

## 기술 검사와 역할 분리

`nhunnhun_blog`의 direct/SP1 preflight는 영양소 TOP 순위 섹션에 `추정` 수치가 들어가는 명백한 구조 오류를 차단한다. 식품 후보군의 충분성·서로 독립된 식품인지 여부는 자동 의미 판정으로 대신하지 않고 이 문서에 따른 작성자 내용 검토에서 확인한다.

새 AI 의미 판정·자동 재작성 루프는 추가하지 않는다.
