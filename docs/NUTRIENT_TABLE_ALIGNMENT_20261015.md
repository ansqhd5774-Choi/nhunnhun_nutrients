# 영양소 표 정렬 기준 — 2026-10-15

## 적용 시점
- 이 기준은 **다음 영양소 신규 글·전체 최신화부터 적용**한다.
- 이미 공개 검증이 끝난 크로세틴 `/284`에는 소급 적용하지 않는다.

## 기본 정렬
- 영양소 본문에 사용하는 모든 표는 **헤더(th)와 본문 셀(td)을 기본 가운데 정렬**한다.
- 가로 정렬은 `text-align:center`, 세로 정렬은 `vertical-align:middle`을 기본값으로 한다.
- 순위, 식품명·원료명, 섭취량, 기간, 함량, 기준, 점검 포인트 등 표 안의 핵심 값은 같은 가운데 정렬 원칙을 적용한다.
- 모바일에서는 기존 가로 스크롤·반응형 표 구조를 유지하되 셀 정렬은 가운데를 유지한다.
- 사용자 요청이 있는 특정 표만 예외 정렬을 허용한다.

## 작성 적용
- 원고 source HTML에서 표를 만들 때 모든 `th`와 `td`가 가운데 정렬되도록 작성한다.
- 렌더링 후 PC와 모바일 공개 검증에서 표 셀의 실제 가운데 정렬 여부를 확인한다.
