# 영양소 형광펜·자연문체 기준 R14

개정일: 2026-10-16

이 문서는 `/115` 플라보노이드 글에서 확정된 사용자 피드백을 다음 영양소 글에 반복 적용하기 위한 강조·문체 기준이다.

## 1. 형광펜의 목적

형광펜은 문장을 통째로 색칠하는 장식이 아니다. 독자가 형광펜 부분만 빠르게 훑어도 문장의 핵심 의미를 재구성할 수 있게 하는 읽기 보조 장치다.

따라서 형광펜 하나는 너무 길어서 문장을 다시 다 읽게 만들어서도 안 되고, 숫자나 단어만 덩그러니 남아 의미를 알 수 없게 해서도 안 된다.

기본 원칙은 다음 한 문장으로 고정한다.

> **형광펜 1개 = 단독으로 읽어도 뜻이 통하는 최소 의미 단위**

## 2. 좋은 강조 단위

다음처럼 `대상 + 조건`, `성분 + 용량`, `지표 + 변화`, `식품 + 함량`, `약물 + 행동`, `제품 + 핵심 성분`이 함께 보이도록 한다.

좋은 예:
- `플라반-3-올 586mg/일`
- `진료실 혈압 2.8/2.0mmHg 감소`
- `혈류매개확장(FMD) 1.7% 증가`
- `퀘르세틴-3-글루코사이드 160mg/일을 4주 섭취`
- `녹차 한 잔에 플라반-3-올 318.74mg`
- `과일·채소·차 섭취가 적은 성인`
- `와파린 복용 중이면 고함량 퀘르세틴 전 의료진 확인`

나쁜 예:
- `586mg/일`
- `2.8/2.0mmHg 감소`
- `1.7% 증가`
- `녹차`
- `추천 조합`

숫자만 읽었을 때 무엇의 수치인지 알 수 없으면 강조 범위를 넓힌다. 반대로 문장 전체를 읽어야 이해되는 길이라면 강조 범위를 줄인다.

## 3. 형광펜만 읽어도 흐름이 이어져야 한다

각 H2에서 형광펜만 위에서 아래로 읽었을 때 다음이 자연스럽게 이어져야 한다.

- ① 무엇인지 → 대표 성분 → 어디서 얻는지 → 주요 작용
- ② 기간 → 실제 섭취량 → 어떤 지표가 얼마나 변했는지 → 누구에게 해당하는지
- ③ 하루 섭취량 → 1회량·횟수 → 언제·어떻게 먹는지
- ④ 식품명 → 실제 섭취 기준 → 함량
- ⑤ 무엇과 함께 먹는지 → 실제 조합 → 약물·상호작용 행동
- ⑥ 결핍·과다 → 핵심 위험 → 제품명·핵심 성분량 → 선택 이유

형광펜만 모아 읽었을 때 `숫자 → 숫자 → 숫자`처럼 주어가 사라지거나, `성분명 → 식품명 → 효과명`처럼 관계가 끊기면 실패로 본다.

## 4. 라벨+콜론형 AI 문체 금지

본문과 형광펜에서 다음처럼 기계적인 `라벨:` 패턴을 반복하지 않는다.

금지 예:
- `정의: 식물의 폴리페놀 화합물군`
- `주요 섭취원: 과일·채소·차·콩류`
- `플라보놀 대표: 퀘르세틴`
- `권장 대상: 과일·채소·차 섭취가 적은 성인`
- `하루 기준: 플라반-3-올 400~600mg`
- `섭취법: 차·베리·사과·코코아로 분산`
- `복용 타이밍: 아침·점심·저녁 분산`
- `녹차: 플라반-3-올 318.74mg/1잔`
- `추천 조합: 플라보노이드 + 비타민 C`
- `제품 선택 기준: 성분 단순 + 하루 섭취량 명확`

자연스러운 문장형으로 바꾼다.

권장 예:
- `식물의 폴리페놀 화합물군`
- `과일·채소·차·콩류에서 섭취`
- `퀘르세틴이 대표적인 플라보놀`
- `과일·채소·차 섭취가 적은 성인`
- `플라반-3-올 하루 400~600mg`
- `차·베리·사과·코코아로 나눠 섭취`
- `아침·점심·저녁으로 나눠 섭취`
- `녹차 한 잔에 플라반-3-올 318.74mg`
- `플라보노이드는 비타민 C가 풍부한 식품과 함께`
- `성분이 단순하고 하루 섭취량이 명확한 제품`

콜론 자체를 전면 금지하는 것은 아니다. 표 헤더, 출처 표기, 명확한 구조상 필요한 곳은 사용할 수 있다. 다만 **본문 강조 문구를 라벨처럼 찍어내는 용도로 반복 사용하지 않는다.**

## 5. 리스트 문체도 자연스럽게 작성

`<li><strong>항목명:</strong> ...</li>` 구조를 기계적으로 반복하지 않는다. 카드형 리스트가 필요해도 항목명 뒤 콜론을 반드시 붙일 필요는 없다.

예:
- `<li><strong>혈압·혈관 관리</strong> ...</li>`
- `<li><strong>염증·내피 지표</strong> ...</li>`
- `<li><strong>권장 대상</strong> ...</li>`

리스트는 구조를 위해 쓰되, 실제 한국어 문장처럼 이어지게 한다.

## 6. 강조 강도

- `strong`은 핵심 설명·중요 구절에 사용한다.
- `mark`는 빠른 스캔이 필요한 핵심 의미 단위에 사용한다.
- `mark > u > strong`은 각 H2에서 가장 중요한 1~2개의 답에만 사용한다.
- 경고·제한 문장만 과도하게 강조하지 않는다.
- 효능, 변화, 실제 용량, 섭취 행동, 식품·함량, 조합, 제품 선택이 강조의 중심이다.

## 7. 작성 후 자체 점검

저장 전 다음을 확인한다.

1. 형광펜 하나만 떼어 읽어도 무엇을 말하는지 알 수 있는가?
2. 숫자가 있다면 그 숫자의 대상·지표·단위가 같이 보이는가?
3. 형광펜만 순서대로 읽어도 해당 H2의 답을 빠르게 유추할 수 있는가?
4. 긴 서술문 전체를 형광펜으로 덮은 곳은 없는가?
5. `정의:`, `추천 조합:`, `제품 선택:`처럼 AI 템플릿 느낌의 라벨+콜론이 반복되지 않는가?
6. 표 안 강조도 `식품 + 함량`, `제품 + 핵심 성분량`처럼 의미가 완결되는가?
7. 사용자에게 보여준 예시 몇 개만 고치고 같은 문제가 다른 H2에 남아 있지 않은가?

## 8. 적용 범위

이 기준은 앞으로 작성·전체 최신화하는 모든 영양소 글에 기본 적용한다. 특정 글의 일부 문구에만 한정된 예외 규칙이 아니다.

플라보노이드 `/115` R5는 이 기준을 처음 전면 적용한 참조 사례다.
