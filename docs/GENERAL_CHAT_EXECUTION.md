# 영양소 실행 계약

이 프로젝트에서는 ansqhd5774-Choi/nhunnhun_nutrients만 사용한다. 작성 기준은 PROJECT_INSTRUCTIONS.txt, 기술 코드는 publishing/와 authoring/다. 다른 저장소를 읽거나 원고를 옮기지 않는다.

완성 JSON을 자동 제출 경로 밖에 먼저 보존하고 GitHub 저장 후 동일 commit 파일과 digest를 확인한다. 신규 posts/와 기존 수정 updates/를 구분하고 sourceId 한 건만 지정한다. 실행 Run·원장·PUBLIC_VERIFIED도 같은 sourceId로만 확인한다. 다른 작업의 성공 기록으로 완료 보고하지 않는다.

일반 Chat에게 로컬 Node·CMD·브라우저 제어를 요구하지 않는다. 자동 실행이 있으면 관찰하고 중복 수동 제출하지 않는다. submitting은 재제출하지 않고 해당 저장소의 검증 전용 복구 경로를 사용한다.

편집 기준과 디자인은 이 저장소에 독립 보관한다. 저장소 접근이 부족해도 다른 카테고리 저장소로 대체하지 않는다.
