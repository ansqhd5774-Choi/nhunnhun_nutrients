## R9 핵심 원칙

영양소 글은 **연구 보고서가 아니라 일반 독자의 검색 질문에 답하는 건강·영양 글**입니다.

정부 자료·영양 DB·진료지침·원문 연구는 사실을 확인하는 내부 근거로 사용합니다. 공개 본문에는 그 자료를 확인해 얻은 **최종 답, 필요한 숫자와 조건, 실제 행동**을 우선합니다.

따라서 연구 설계명이 결론 이해에 필요하지 않으면 `사람 연구`, `임상시험`으로 바꾸어 남기는 것이 아니라 **연구 표현 자체를 생략하고 확인된 결과를 바로 씁니다.** 표본수·무작위·대조군·분석법·통계값·DB 비교 과정도 독자 판단에 꼭 필요할 때만 보조합니다.

기본 문장 순서는 다음과 같습니다.

`쉬운 답 → 필요한 숫자·조건 → 행동`

작성자의 조사 과정, QA 과정, 자료를 비교하기 어려운 이유, TOP 순위를 만들지 않은 이유는 기본적으로 본문에 쓰지 않습니다.

## 기본 구조

1. 정의·주요 성분·작용
2. 효능·기대 변화·권장 대상·제품 형태
3. 실제 섭취량·복용법·기간·대표 제품
4. 풍부한 식품과 실제 함량
5. 함께 섭취할 영양소·보충제 조합
6. 결핍·과다 섭취

대표 이미지와 짧은 도입 다음에는 `효능 / 누가 / 복용 / 기간 / 조합 / 주의`의 **핵심만 먼저 6카드**를 둡니다. 하단에 같은 내용을 반복하는 `핵심 정리` H2는 만들지 않습니다.

## ② 효능 작성 핵심

사람 근거가 있는 효능은 작성 단계에서 `누가 / 얼마를 / 얼마나 오래 / 무엇이 변했는가`를 확인합니다.

공개 본문은 연구 보고서식 문장보다 다음처럼 씁니다.

> 무릎 골관절염이 있는 성인이 커큐민 500mg을 하루 2회, 8주 섭취했을 때 통증과 걷기 기능이 개선된 결과가 있습니다.

같은 사실을 `101명을 대상으로 한 무작위 대조시험에서…`로 시작하지 않습니다. 표본수나 설계가 실제 적용 범위를 바꿀 때만 짧게 남깁니다.

## ④ 식품·함량 작성 핵심

④의 첫 질문은 **`어디에 얼마나 들어 있는가?`**입니다.

표는 기본적으로 다음 정보를 중심으로 구성합니다.

| 식품·원료 | 함량 | 기준 | 실제 섭취 참고 |
| --- | ---: | --- | --- |
| 식품 A | 값 | 생것·건조·100g 등 | 필요 시 1회량 |

- 동일 기준으로 비교 가능한 독립 식품이 충분하면 TOP7→TOP5→TOP3 순으로 축소할 수 있습니다.
- 비교 가능한 3개도 없으면 순위를 만들지 않고 확인된 식품과 함량을 그대로 보여줍니다.
- 기준이 다른 값도 유용하면 버리지 말고 비순위 표에 기준을 명시합니다.
- `DB가 달라서`, `분석법이 달라서`, `왜 순위를 만들지 않았는지`를 장황하게 설명하지 않습니다. 필요한 차이는 표 아래 한두 문장으로 끝냅니다.
- 같은 핵심 원료를 넣은 가공품 여러 개로 TOP을 채우지 않습니다.
- 추정·환산·배합률 계산값으로 TOP 순위를 만들지 않습니다.

공통 `publishing/direct-design.mjs`가 PC 2열·모바일 1열 카드로 렌더링합니다. 카드에는 상세 연구명·긴 기전·출처 설명을 넣지 않습니다.

## 강조·이미지

- 영양소 direct/SP1 강조 누락 방지 하한: `strong 25 / mark 14 / mark>u>strong 8`
- 하한을 맞추기 위해 없는 효능·위험·수치를 만들지 않습니다.
- 강조의 첫 기준은 현재 H2의 질문에 가장 직접 답하는지 여부입니다.
- 의미 톤은 `positive / info / caution / negative`를 사용합니다.
- 신규 및 전체 수정은 서로 다른 본문 이미지 최소 3개를 사용하고 HTTPS·alt·원출처·저작자·라이선스·중복을 확인합니다.

## 저장 전 한 번만 확인

저장 전 `내용 검토`에서 다음을 확인합니다.

- 각 H2 첫 문장이 질문에 바로 답하는가?
- 본문에 작성자의 조사·검증·변명 과정이 들어갔는가?
- `연구/논문/시험/DB/분석법`을 지워도 뜻이 유지된다면 지웠는가?
- ②가 대상·섭취량·기간·변화를 담되 연구 보고서처럼 보이지 않는가?
- ④의 첫 답과 표가 식품명과 실제 함량을 바로 보여주는가?
- 카드·강조·본문의 수치와 의미가 일치하는가?

별도 AI 의미 판정이나 자동 재작성 루프를 추가하지 않습니다. Gate 0·preflight·공개 검증에서는 저장 무결성·기술 계약·실제 공개 반영을 확인합니다.
