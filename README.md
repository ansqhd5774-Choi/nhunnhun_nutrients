## R11 핵심 원칙

영양소 글은 **한국 일반 독자가 실제로 먹고 선택하는 데 필요한 정보를 빠르게 이해하는 건강·영양 글**입니다.

자료 확인은 작성자가 사실과 숫자를 틀리지 않기 위해 수행합니다. 공개 본문은 자료를 평가하거나 조사 과정을 설명하는 영역이 아니라 **최종 답·핵심 숫자·실제 행동**을 전달하는 영역입니다.

기본 문장 흐름은 다음과 같습니다.

`쉬운 답 → 필요한 숫자·조건 → 실제 행동`

자료 부족·한계·반박 설명으로 분량을 채우지 않습니다. 실제 부작용·상한·약물 상호작용·알레르기·금기처럼 독자의 안전과 행동을 바꾸는 정보는 분명하게 유지합니다.

## 사용자 확정 6개 소제목

아래 문구·순서·의미는 사용자 승인 없이 변경하지 않습니다.

1. **정의와 주요 성분 및 작용은 무엇인가?**
2. **한 달 복용 후 기대되는 신체 변화와 권장 대상은 누구인가?**
3. **일일 권장 섭취량과 효과적인 섭취법은 무엇인가?**
4. **풍부한 식품 TOP7과 각 식품의 평균 함유량은 얼마인가?**
5. **함께 섭취하면 좋은 영양소와 주의할 상호작용은 무엇인가?**
6. **결핍 및 과다 복용의 위험, 예방 가능한 질병과 추천 제품은 무엇인가?**

대표 이미지와 짧은 도입 다음에는 `효능 / 누가 / 복용 / 기간 / 조합 / 주의`의 핵심만 먼저 6카드를 둡니다. 하단에 같은 내용을 반복하는 `핵심 정리` H2는 만들지 않습니다.

## ② 작성 핵심

②는 독자가 **한 달 정도 먹었을 때 몸에서 어떤 변화를 기대할 수 있는지와 누구에게 유용한지** 바로 이해하게 작성합니다.

필요한 경우 대상·섭취량·기간·변화를 쉬운 문장으로 제시하고, 독자가 생활에서 이해할 수 있는 의미를 함께 설명합니다.

## ④ 작성 핵심

④는 **TOP7 식품명과 평균 함유량**이 중심입니다.

기본 표:

| 순위 | 식품 | 평균 함유량 | 기준 |
| ---: | --- | ---: | --- |
| 1 | 식품 A | 값 | 100g 등 |

- 같은 원료 파생 가공품으로 순위를 채우지 않습니다.
- 계산·환산·배합률 적용값을 실제 평균값처럼 순위에 넣지 않습니다.
- 확인 가능한 식품이 7개보다 적으면 숫자를 만들지 않고 확보한 정보를 최대한 보여줍니다.
- 분석방법·DB 비교·작성자의 순위 판단 과정은 본문과 표의 중심으로 만들지 않습니다.

## 강조·이미지

- 영양소 direct/SP1 강조 누락 방지 하한: `strong 25 / mark 14 / mark>u>strong 8`
- 하한을 맞추기 위해 없는 효능·위험·수치를 만들지 않습니다.
- 강조는 각 H2의 핵심 답과 실제 행동 정보를 우선합니다.
- 신규 및 전체 수정은 서로 다른 본문 이미지 최소 3개를 사용하고 HTTPS·alt·원출처·저작자·라이선스·중복을 확인합니다.

## 저장 전 확인

- 사용자 확정 6개 소제목이 그대로 유지됐는가?
- 각 H2 첫 문장이 질문에 바로 답하는가?
- 작성자의 조사·검증 과정이 독자 본문을 차지하지 않는가?
- 자료 부족·일반적 한계 문장이 효능·복용·함량·조합 같은 실용 정보를 밀어내지 않는가?
- 실제 안전정보는 빠지지 않았는가?
- 카드·강조·표·본문의 숫자와 의미가 일치하는가?

별도 AI 의미 판정이나 자동 재작성 루프를 추가하지 않습니다. Gate 0·preflight·공개 검증은 저장 무결성·기술 계약·실제 공개 반영을 확인합니다.
