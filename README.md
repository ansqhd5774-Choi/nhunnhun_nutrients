## R13 + R14 핵심 원칙

영양소 글은 **한국 일반 독자가 실제로 먹고 선택하는 데 필요한 정보를 빠르게 이해하는 건강·영양 글**입니다.

기본 문장 흐름은 `쉬운 답 → 필요한 숫자·조건 → 실제 행동`입니다. 고정 글자수는 두지 않지만 각 소제목의 질문은 끝까지 답합니다.

본문은 평문과 형광펜만으로 만들지 않습니다. 여러 항목을 비교할 때는 카드형 리스트, 수치 비교는 표, 실제 맥락은 이미지로 구조화합니다. 특히 ②·③·⑤·⑥에서 항목이 여러 개라면 `<ul><li><strong>항목명</strong> ...</li></ul>` 구조를 우선 사용해 direct 디자인에서 카드로 읽히게 합니다. ④ TOP7은 표가 중심입니다.

**형광펜만 위에서 아래로 읽어도 ① 정의·작용, ② 변화·대상, ③ 섭취량·섭취법, ④ 식품·함량, ⑤ 조합·상호작용, ⑥ 결핍·과다·예방·제품 선택의 핵심 답을 모두 회수할 수 있어야 합니다.** 경고·주의만 강조하지 않고 효능·수치·섭취법·식품·조합·제품 선택이 중심이 되게 합니다.

형광펜은 숫자나 단어만 떼어 칠하지 않고 **단독으로 읽어도 뜻이 통하는 최소 의미 단위**로 적용합니다. `성분+용량`, `지표+변화`, `식품+함량`, `대상+조건`, `약물+행동`, `제품+핵심 성분`이 기본 단위입니다. `정의:`, `추천 조합:`, `제품 선택:`처럼 라벨+콜론을 반복하는 AI 템플릿형 문체는 사용하지 않고 자연스러운 한국어 구절로 작성합니다.

## 사용자 확정 6개 소제목

1. **정의와 주요 성분 및 작용은 무엇인가?**
2. **한 달 복용 후 기대되는 신체 변화와 권장 대상은 누구인가?**
3. **일일 권장 섭취량과 효과적인 섭취법은 무엇인가?**
4. **풍부한 식품 TOP7과 각 식품의 평균 함유량은 얼마인가?**
5. **함께 섭취하면 좋은 영양소와 주의할 상호작용은 무엇인가?**
6. **결핍 및 과다 복용의 위험, 예방 가능한 질병과 추천 제품은 무엇인가?**

대표 이미지와 짧은 도입 다음에는 `효능 / 누가 / 복용 / 기간 / 조합 / 주의`의 핵심만 먼저 6카드를 둡니다.

## ④ 작성 핵심

④는 식품 TOP7과 함량을 표로 보여줍니다. 직접 섭취하는 식품과 그 성분을 이용해 만든 가공·발효식품의 성격이 다르면 구분합니다. 제품 1회 제공량을 식품의 풍부함 순위로 사용하지 않습니다. 실제 평균값·범위·단일값을 구분하고 확인 가능한 수치만 제시합니다.

## 강조·이미지

- 강조 누락 방지 하한: `strong 25 / mark 14 / mark>u>strong 8`
- 강조는 각 H2의 핵심 답과 실제 행동 정보를 우선합니다.
- 형광펜은 본문의 압축판이어야 합니다.
- 형광펜 하나는 너무 길어 문장을 다시 읽게 해서도, 너무 짧아 무엇의 수치인지 모르게 해서도 안 됩니다.
- 신규 및 전체 수정은 서로 다른 본문 이미지 최소 3개를 사용하고 HTTPS·alt·원출처·저작자·라이선스·중복을 확인합니다.

## 저장 전 확인

- 6개 소제목이 그대로 유지됐는가?
- 각 H2 첫 문장이 질문에 바로 답하는가?
- 각 질문에 필요한 정보가 충분한가?
- 여러 항목이 카드형 리스트 또는 표로 구조화됐는가?
- 형광펜만 읽어도 ①~⑥ 핵심 답이 모두 이어지는가?
- 형광펜 하나만 떼어 읽어도 대상·수치·변화의 의미가 통하는가?
- 라벨+콜론형 문구가 본문·형광펜에 반복되지 않는가?
- 사용자에게 지적받은 예시만 고치고 동일 문제가 다른 H2에 남아 있지 않은가?
- 카드·강조·표·본문의 숫자와 의미가 일치하는가?

별도 AI 의미 판정이나 자동 재작성 루프를 추가하지 않습니다. Gate 0·preflight·공개 검증은 저장 무결성·기술 계약·실제 공개 반영을 확인합니다.
